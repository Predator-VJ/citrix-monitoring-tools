## 📋 &nbsp;Script Arsenal

<div align="center">

| Script | Description | Category |
|--------|-------------|----------|
| `Get-CitrixSessionInfo.ps1` | Reports active/disconnected ICA sessions | 👥 Sessions |
| `Get-CitrixLicenseStatus.ps1` | License Server status & usage | 🔑 Licensing |
| `Get-CitrixMachineStatus.ps1` | VDA machine availability & health | 🖥️ Machines |
| `Get-CitrixAppUsage.ps1` | Application usage statistics | 📊 Analytics |
| `Test-CitrixServices.ps1` | Check critical Citrix services | 🔧 Services |
| `Clear-CitrixIdleSessions.ps1` | Log off idle/disconnected sessions | 🧹 Cleanup |

</div>

> ⚠️ **Note:** All scripts require the **Citrix PowerShell SDK** (Citrix.Broker.Admin.V2) installed on your Delivery Controller.

---

## ⚙️ &nbsp;Requirements

- Windows Server with **Citrix Virtual Apps and Desktops** Delivery Controller
- **Citrix PowerShell SDK** (installed with Citrix installation media)
- PowerShell 5.1+ with Administrator privileges
- Appropriate Citrix admin role/permissions

---

## 🚀 &nbsp;Quick Start

```powershell
# Clone the repository
git clone https://github.com/Predator-VJ/citrix-monitoring-tools.git
cd citrix-monitoring-tools

# Run any script (on Delivery Controller)
.\Get-CitrixSessionInfo.ps1
.\Get-CitrixMachineStatus.ps1
.\Get-CitrixLicenseStatus.ps1
```
